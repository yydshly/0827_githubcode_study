00B / ECOSYSTEM COMPARISON

同类库不是一种产品，而是一条生产链

有的负责解析 PDF 和视频，有的负责判断什么值得成为能力，有的负责构造、评测、标准或分发。把它们放在同一条链上，才能看清谁是替代、谁是互补。

OUR POSITION Cangjie Skill 的差异化位置：方法识别与能力蒸馏

它不需要自己完成所有来源解析、评测运行和市场分发；最合理的路线是保留五路提取与三重验证，再组合其他工具的工程能力。
