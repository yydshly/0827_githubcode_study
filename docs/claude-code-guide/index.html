不要凭“感觉不错”判断

用对照实验识别真实价值

保持模型、代码和任务不变，只改变脚手架层。你要测的是控制系统带来的增量，不是 M3 本身会不会写代码。

PRODUCTION GAP

这个仓库最值得学，
也最不能照搬的地方

示例的使命是展示能力面，不是替你完成生产治理。复制前必须做权限收敛、路径适配、秘密脱敏、依赖锁定和评测。

  • 权限

    settings.json 允许面较宽从最小权限重新建立 allow / deny。

  • 日志

    工具事件可能包含敏感信息做字段过滤、轮转和并发安全。

  • 路径

    Hook 存在环境相关路径改为项目可发现的解释器与依赖。

  • 供应链

    动态拉取 latest 存在漂移固定版本、校验来源并做隔离。

  • 副作用

    /pr 与 /review 涉及外部写入加入 dry-run 和人工批准门。
