一句话判断

模型决定效果上限，算力决定本地能不能跑，Modly 决定这些能力能否被统一、组合并进入资产生产流程。

它是

3D 生成模型的工作流与适配平台

统一模型安装、参数、输入输出、进程隔离、节点编排和结果预览。

它不是

新的图生 3D 基础模型

不会替代 Hunyuan3D、TripoSG、TRELLIS 等模型的几何和纹理能力。

直接后果

本地使用会依赖电脑性能

尤其依赖 NVIDIA GPU 与显存；也可以通过云端 API 把算力依赖移出本机。

01 / MECHANISM

它的原理，是把不同“发动机”装进同一条流水线

Modly 的价值不在于重新训练模型，而在于把模型从脚本和环境依赖中抽出来，变成可安装、可配置、可连接的工作流节点。

  • 构成最终质量的主要上限
源码依据

Modly 通过生成器注册表发现扩展，以基础生成器约束加载、生成和卸载；扩展以独立进程通信。它是比“薄 API 包装”更完整的运行与编排层，但没有替代底层模型。

04 / VALUE

它对我们的价值，不是“让弱模型变强”

真正价值是把快速变化、部署方式各异的模型纳入同一资产流程，降低试错、切换和组合成本。

01

低成本比较

同一批输入在多个模型间切换，避免每个模型各写一套临时脚本。

02

本地与云端混合

轻量任务本地完成，难例或高质量任务自动转到商业 API。

03

资产后处理串联

生成之后继续连接去背景、贴图、减面、格式转换和质量检查。

04

屏蔽供应商差异

把上层工作流与具体模型解耦，降低模型迭代带来的迁移成本。

适合
  • 游戏、WebGL、AR 的概念资产与背景道具
  • 商品或物体的快速 3D 原型
  • UGC 和批量内容生产
  • 模型评测、对比和后处理研究
  • 对精确尺寸没有硬性要求的视觉资产
不宜直接承诺
  • 精确尺寸和装配约束的 CAD / 工业建模
  • 无需人工清理即可上线的英雄级角色
  • 单张图片恢复绝对真实的不可见结构
  • 天然可动画、可变形的高质量拓扑
  • 不经授权复核的商业资产批量生产
05 / DECISION

先根据目标和设备选路线

这不是在线推理器，而是一个本地决策辅助。选择最接近的条件，查看建议的最小模型组合与下一步。

NO LOCAL GPU

先接一个云端 API，不下载模型

用 Meshy、Tripo 或 Rodin 跑一批真实业务图片，先确认“生成出的资产是否真的节省人工建模时间”。本机只需要浏览器和 3D 预览能力。

主方案：Tripo / Meshy / Rodin本地：仅工作流与预览目标：验证业务价值
下一步

准备 30 张有代表性的图片，记录正背面一致性、网格质量、PBR、失败率、耗时和单次成本。
