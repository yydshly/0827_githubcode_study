One index,
many studies.

统一 slug 连接源码、研究记录和 Web 页面。门户只负责发现与导航，各子项目保留自己的结论、证据和视觉表达。

新增项目流程

固定研究对象记录上游仓库、commit 或 release，避免结论随代码漂移。
建立研究记录在 studies/<slug> 中保存能力、原理、证据、边界和采用判断。
制作独立页面在 docs/<slug> 中形成可分享的结论页面，使用相对资源路径。
验证并发布检查桌面/移动端、链接和 GitHub Pages，再把状态改为 published。
