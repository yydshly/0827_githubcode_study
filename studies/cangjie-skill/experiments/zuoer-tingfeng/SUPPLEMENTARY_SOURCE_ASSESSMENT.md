# 用户提供 GitHub 语料评估

## 结论

用户提供的
[`zhuxxsherlocked/study-blog/左耳听风`](https://github.com/zhuxxsherlocked/study-blog/tree/main/%E5%B7%A6%E8%80%B3%E5%90%AC%E9%A3%8E)
不是《左耳听风：传奇程序员练级攻略》的按章电子版，而是极客时间《左耳听风》专栏的镜像式 Markdown 集合。

它可以用于：

- 建立“专栏 → 纸质书”主题来源假设；
- 作为阶段 0 的外部背景和阶段 1.5 的外部对照；
- 单独建立“左耳听风专栏代理语料”实验；
- 检验同一作者内容经过编辑重组后，Skill 提取结果是否发生变化。

它不能用于：

- 冒充 ISBN `9787121466809` 的整书正文；
- 给纸质书中的主张提供页码级证据；
- 判断一个观点是否在纸质书两个独立段落中出现；
- 直接解除当前整书实验的 `blocked-on-authorized-full-text` 状态。

## 来源与许可风险

- 仓库公开不等于内容获得开放许可；仓库树中没有发现 `LICENSE` 或 `COPYING`。
- 文件内容呈现为陈皓第一人称课程正文，而提交者不是陈皓或已知授权方。
- 因此本项目不把该镜像复制进 Git、不把它作为开放许可正文发布，也不输出大段原文。
- 如用于研究，只保留短引用、来源链接和转化后的方法论，并明确标记为“第三方专栏镜像”。

## 推荐实验设计

保留两个不同实验对象：

1. **Book Track**：纸质书全文，严格按 ISBN 和页码执行 RIA-TV++；当前等待扫描/OCR。
2. **Column Proxy Track**：119 篇专栏语料，单独生成 Skill Pack；输出不得冠以“整书分析”。

当 Book Track 可用后，再比较两套结果的候选重合率、Skill 路由差异、编辑压缩损失和新增主题。
