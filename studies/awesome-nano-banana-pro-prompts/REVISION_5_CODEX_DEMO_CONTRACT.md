# Revision 5 — Codex 生图补全契约

## 目标与授权

- 用户授权：直接使用 Codex 生图并补全 Prompt Lab 页面。
- 模式：revision-led / implementation。
- 目标：让 12 项实验都有可见效果，同时保持模型来源真实可辨。

## 信息架构

- `Gemini Web 实测`：E01、E02，保留原有成功与失败结论。
- `Codex 跨模型演示`：E03–E12，用于展示提示词方向与页面价值，不作为 Gemini 能力验证。
- 参考图任务 E04–E06 使用同一张 Codex 生成的虚构人物锚点图。
- 编辑任务 E11 使用 E01 基线图；E12 使用 E02 基线图。

## 视觉与交互约束

- 保留现有 Editorial Flow、明暗主题、筛选、提示词展开与复制功能。
- 每张实验卡展示对应结果或演示图，不再使用抽象占位。
- 用不同状态标签区分“Gemini 实测”和“Codex 演示”。
- 图片采用合适的 `object-fit`，不得裁掉关键信息或制造横向溢出。

## 边界

- 不把 Codex ImageGen 输出描述为 Gemini 或 Nano Banana Pro 实测结果。
- 不为人物参考图声称真实身份保持；使用虚构人物锚点，只观察构图与视觉连续性。
- 不建设数据库、社区、投稿、多语言后台或自动化生成服务。
- 不改动其他研究项目。
