# Revision 3 — Prompt Lab 修复契约

## 授权与模式

- 用户反馈：实验页仍是半成品。
- 模式：revision-led / repair-led。
- 授权：修复现有页面并完成浏览器验收；不扩展到后端、Gemini 自动化或更多真实生图。

## 保留内容

- 4 条能力路线与 12 项实验范围。
- 统一评分量表。
- 5 个候选提示词骨架。
- 现有视觉语言、明暗主题与响应式基础。
- 返回主能力图谱和上游仓库的入口。

## 已观察缺陷

1. 首屏以 `12 PLANNED / 0 EXECUTED / 0 VERIFIED` 为视觉焦点，让页面像未开工的项目面板。
2. 12 张实验卡只有假设和变量，没有可复制的执行提示词，主旅程在卡片处中断。
3. 已经产生的 Gemini Web 结果没有进入页面，缺少真实成功与失败证据。
4. 5 个模板可以复制，但与上方 12 项实验的关系不清楚。
5. 页面把“研究设计已完成”和“模型效果已验证”混成一种项目状态。

## 修复方向

- 页面定位从 `Experiment Track` 调整为 `Prompt Lab / 提示词实验台`。
- 首屏直接说明页面提供什么：12 条可执行提示词、1 组真实对比、5 个复用骨架、1 套评分规则。
- 每张实验卡提供完整提示词预览、输入要求、通过条件和复制按钮。
- 新增 E01 真实结果区，展示首次成功与单变量编辑未生效的对比。
- 使用 `可直接执行 / 已有样例` 表达页面准备度；模型层只在真实证据处声明结果。

## 主要旅程

```text
进入 Prompt Lab
→ 按能力路线筛选
→ 查看实验目的与完整执行提示词
→ 一键复制
→ 查看 E01 真实成功/失败证据
→ 使用统一评分或候选模板
```

## 验收标准

- DOM 中存在 12 张实验卡、12 个实验复制按钮、5 个模板复制按钮。
- 四条路线各筛出 3 张卡片。
- E01 明确标记为“已有样例”，其他条目标记为“可直接执行”。
- 两张 E01 本地结果图能够加载，并分别说明命中项与未命中项。
- 复制实验提示词和复制候选模板均有可见反馈。
- 主能力图谱入口、来源链接和页面锚点可达。
- 1440、1024、390 三档无横向溢出。
- 明暗主题、键盘 Tab/Enter、可见焦点和 reduced-motion 可用。
- 浏览器控制台错误为 0，JavaScript 与 Git 空白检查通过。

## 范围边界

- 不声称 12 项实验已经全部执行。
- 不调用 Gemini，不处理登录态或费用。
- 不建设数据库、账户、投稿、审核、多语言社区或自动化任务系统。
- 不改动其他研究项目。
